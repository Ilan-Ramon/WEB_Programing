# שיעור 5 — תרגול HTML ו-CSS בסיסי

קובץ פתיחה לתרגול חופשי: בונים דף אישי מהיסוד ומתרגלים אלמנטים ותכונות עיצוב בסיסיות.

## איך מתחילים
1. פתחו את `practice.html` בדפדפן.
2. פתחו את שני הקבצים בעורך הקוד.
3. משימה 1 — דף בסיסי: כותרת, פסקאות, תמונה, קישור, רשימה.
4. משימה 2 — צבעים ורקעים: `color`, `background-color`.
5. משימה 3 — מסגרות ורווחים: `border`, `border-radius`, `padding`, `margin`.
