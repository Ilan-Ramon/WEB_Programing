# שיעור 6 — בניית מחשבון: שכבת התצוגה

קובץ פתיחה לבניית המראה של מחשבון — תצוגה ושורת כפתורים ראשונה — עם HTML ו-CSS Grid.
בשלב הזה הכפתורים לא באמת מחשבים כלום; הלוגיקה (עם JavaScript) מגיעה בשיעור הבא.

## איך מתחילים
1. פתחו את `calculator.html` בדפדפן.
2. פתחו את שני הקבצים בעורך הקוד.
3. השלימו את המחשבון ל-16 כפתורים (9-0, נקודה, ו-`+ - * /=`), מסודרים ב-4 שורות.
4. תנו לכפתורי הפעולות (`class="operator"`) צבע שונה.
